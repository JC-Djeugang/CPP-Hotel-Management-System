# C++ Hotel Management System

## Overview
This project is a C++ console application developed to simulate basic hotel management operations. It allows hotel staff to record room occupancy across multiple floors while calculating revenue and occupancy statistics.

## Features

- Hotel location input
- Floor and room validation
- Supports four room types:
  - Single
  - Double
  - King
  - Suite
- Calculates:
  - Hotel revenue
  - Total rooms
  - Occupied rooms
  - Unoccupied rooms
  - Occupancy rate
- Identifies the floor with the fewest rooms
- Displays a warning if occupancy falls below 60%

## Technologies

- C++
- Arrays
- Loops
- Conditional Statements
- Input Validation
- Formatted Output
